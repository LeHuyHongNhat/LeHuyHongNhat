# Fonts

Latin and Vietnamese subsets of **Geist** and **Geist Mono** (variable, weights 100–900),
© Vercel, licensed under the [SIL Open Font License 1.1](https://github.com/vercel/geist-font/blob/main/OFL.txt).

`../build.py` embeds them into the SVG cards as base64 so the cards render with the same type on
every machine (an SVG shown as an image cannot load fonts from the network).
